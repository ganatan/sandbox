# SSH et clés SSH

## Connexion distante

```bash
ssh user@serveur
```

## Connexion sur un port spécifique

```bash
ssh -p 2222 user@serveur
```

## Générer une clé ed25519

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519
```

## Afficher la clé publique

```bash
cat ~/.ssh/id_ed25519.pub
```

## Installer la clé publique sur le serveur

```bash
ssh-copy-id user@serveur
```

## Choisir une identité

```bash
ssh -i ~/.ssh/id_ed25519 user@serveur
```

## Tester la connexion

```bash
ssh -v user@serveur
```

## Exécuter une commande distante

```bash
ssh user@serveur 'hostname'
```

## Créer un tunnel local

```bash
ssh -L 8080:127.0.0.1:3000 user@serveur
```

## Démarrer l'agent

```bash
eval "$(ssh-agent -s)"
```

## Ajouter une clé à l'agent

```bash
ssh-add ~/.ssh/id_ed25519
```

## Lister les clés chargées

```bash
ssh-add -l
```

## Vérifier la configuration

```bash
ssh -G serveur
```

## Permissions usuelles de .ssh

```bash
chmod 700 ~/.ssh
```

## Permissions d'une clé privée

```bash
chmod 600 ~/.ssh/id_ed25519
```
