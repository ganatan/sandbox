# Git sous Linux

## Version

```bash
git --version
```

## Nom

```bash
git config --global user.name 'Developpeur'
```

## E-mail

```bash
git config --global user.email 'user@example.com'
```

## Configuration

```bash
git config --list
```

## Cloner

```bash
git clone https://github.com/ganatan/sandbox.git
```

## Statut

```bash
git status
```

## Branches

```bash
git branch -a
```

## Créer branche

```bash
git switch -c documentation
```

## Ajouter

```bash
git add .
```

## Commit

```bash
git commit -m 'docs: mise à jour'
```

## Historique

```bash
git log --oneline -10
```

## Différences

```bash
git diff
```

## Récupérer

```bash
git pull --ff-only
```

## Publier

```bash
git push -u origin documentation
```

## Dépôts distants

```bash
git remote -v
```
