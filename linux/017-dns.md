# DNS et résolution de noms

## Afficher les résolveurs

```bash
cat /etc/resolv.conf
```

## Résoudre un nom

```bash
getent hosts example.com
```

## Résoudre IPv4

```bash
getent ahostsv4 example.com
```

## Requête DNS A

```bash
dig example.com A
```

## Requête DNS AAAA

```bash
dig example.com AAAA
```

## Requête DNS MX

```bash
dig example.com MX
```

## Requête DNS TXT

```bash
dig example.com TXT
```

## Interroger un serveur précis

```bash
dig @1.1.1.1 example.com A
```

## Résolution inverse

```bash
dig -x 8.8.8.8
```

## Réponse courte

```bash
dig +short example.com
```

## Consulter les hôtes locaux

```bash
cat /etc/hosts
```

## Afficher configuration systemd-resolved si disponible

```bash
resolvectl status
```

## Tester HTTP après résolution

```bash
curl -I https://example.com
```
