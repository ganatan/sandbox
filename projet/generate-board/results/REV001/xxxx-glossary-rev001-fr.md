# Glossaire — Open Source

**Société :** ganatan  
**Projet :** xxxx  
**Révision :** REV001

**Statut :** SIMULATION

| Terme | Définition |
|---|---|
| **AGPL** | Licence copyleft incluant certaines obligations liées à l'utilisation via un réseau. |
| **Apache-2.0** | Licence Open Source permissive publiée par l'Apache Software Foundation. |
| **BSD** | Famille de licences permissives, notamment BSD-2-Clause et BSD-3-Clause. |
| **Copyleft** | Principe de licence imposant des conditions lors de certaines redistributions. |
| **GPL** | GNU General Public License ; famille de licences à copyleft fort. |
| **ISO** | Organisation internationale de normalisation. |
| **ISO/IEC 5230** | Norme OpenChain relative aux programmes de conformité des licences Open Source. |
| **ISO/IEC 5962** | Norme internationale définissant SPDX. |
| **JSON** | JavaScript Object Notation ; format d'échange de données structurées. |
| **LGPL** | GNU Lesser General Public License ; famille de licences à copyleft faible. |
| **MIT** | Licence logicielle permissive. |
| **OpenChain** | Initiative proposant des référentiels de conformité et de sécurité Open Source. |
| **OSS** | Logiciel Open Source. |
| **REV** | Identifiant de révision documentaire. |
| **SBOM** | Nomenclature des composants logiciels et de leurs dépendances. |
| **SPDX** | Standard d'échange d'informations sur les logiciels et licences. |

Seuls les acronymes et concepts de référence sont définis ; aucune conclusion de conformité n'est fournie.
