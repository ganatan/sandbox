# IntelliJ IDEA — Raccourcis

## Commentaires

**Configuration**

`File` → `Settings` → `Keymap`

Rechercher `Comment`.

Supprimer les raccourcis existants pour :

- `Comment with Line Comment`
- `Comment with Block Comment`

Clic droit sur `Comment with Line Comment` → `Add Keyboard Shortcut`.

**Nouveau raccourci**

```text
Ctrl + :
```

Valider avec `OK`.

---

## Terminal

**Raccourci**

```text
Alt + F12
```

Accès par le menu :

`View` → `Tool Windows` → `Terminal`

---

## Formatage du code

**Configuration**

`File` → `Settings` → `Keymap`

Rechercher `Reformat Code`.

Clic droit sur `Reformat Code` → `Add Keyboard Shortcut`.

**Nouveau raccourci**

```text
Alt + Maj + F
```

Valider avec `OK`.

En cas de conflit :

- `Remove` : supprimer l'affectation concurrente.
- `Leave` : conserver les deux affectations.

---

## Indentation

**Java**

`File` → `Settings` → `Editor` → `Code Style` → `Java` → `Tabs and Indents`

```text
Indent   : 2
Tab size : 2
```

**XML**

`File` → `Settings` → `Editor` → `Code Style` → `XML`

```text
Indent   : 2
Tab size : 2
```

## Fermeture d'un onglet

**Configuration**

`File` → `Settings` → `Keymap`

Rechercher `Close` dans les actions de l'éditeur :

`Main Menu` → `Window` → `Editor Tabs` → `Editor Close Actions`

Clic droit sur l'action `Close` → `Add Keyboard Shortcut`.

**Nouveau raccourci**

```text
Ctrl + W
```

Valider avec `OK`.

Attention : `Ctrl + W` peut déjà être affecté à une autre action.

En cas de conflit :

- `Remove` : supprimer l'affectation concurrente.
- `Leave` : conserver les deux affectations.
